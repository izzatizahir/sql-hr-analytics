# HR Analytics Using SQL

## Project Overview

This project uses SQL to analyze employee attrition and workforce trends. The analysis focuses on employee satisfaction, salary levels, promotions, workload, tenure, and workplace accidents to identify factors influencing employee retention.

## Dataset

HR Employee Attrition Dataset

## Business Questions

1. What is the total number of employees?
2. How many employees left the company?
3. Which department has the highest attrition?
4. Does salary affect attrition?
5. What is the average employee satisfaction level?
6. Does promotion reduce turnover?
7. Which tenure group experiences the highest attrition?
8. Which department works the longest hours?
9. Does work accident history affect attrition?

## SQL Skills Demonstrated

- SELECT
- WHERE
- COUNT()
- SUM()
- AVG()
- ROUND()
- GROUP BY
- ORDER BY
- Aggregate Analysis

## Key Findings

- Sales recorded the highest number of employee departures.
- Low salary employees experienced the highest attrition.
- Employees with low satisfaction levels were more likely to leave.
- Promoted employees had significantly lower attrition.
- Employee turnover peaked around the fifth year of service.
- Average working hours were relatively consistent across departments.
